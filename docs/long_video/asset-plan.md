# Memory Lab Editorial — Archive Asset Plan

## Rule

This file is an acquisition plan, not an `assetMap` and not production readiness. Every selected item must still pass the existing Zhiying asset backend with a physical file, exact scene/requirement binding, provenance, and a usable license. Journal figures are never assumed reusable merely because the underlying paper is cited.

The visual system uses authentic material only when it establishes a person, document, experiment, procedure, or historical context. Abstract mechanisms are drawn in Remotion. No AI image may be presented as archive.

## Planned production use

- Target unique real/archive assets: 15–24 after rights closure.
- Maximum reuse: a source may reappear only when the narration returns to that exact evidence. Reframing or annotating the same file does not count as a new unique asset.
- Archive-heavy zones: Bartlett/source chain, Loftus history, reconsolidation historical context, flashbulb longitudinal record, eyewitness procedure, autobiographical-memory method.
- Mechanism-heavy zones: DRM, gist/detail, source monitoring, confidence contamination, memory/belief classification. These use original Remotion graphics rather than illustrative stock.
- Sensitive imagery: no crash casualties, disaster impact footage, identifiable suspect arrays, distressed children, or synthetic “historical” reenactment.

## Pre-bind stop gate

An item stays out of production if any of these remains unknown: exact source page, creator, date, reuse license, attribution, physical file integrity, or narrative purpose. “Available online” is not a license.
