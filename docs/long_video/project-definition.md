# Extreme Long Video — Project Definition

- Topic: 《你记得的，真的发生过吗？——从虚假记忆、目击证词到大脑如何重写过去》
- Core question: 为什么错误回忆也会产生确信感，以及在什么条件下必须依靠外部证据校验？
- Audience: 普通中文观众，不预设心理学背景。
- Target duration: 16–18 分钟；15–20 分钟为可接受边界，不用重复观点填时长。
- Tone: 克制、思辨、证据驱动；不把“记忆会重建”写成“记忆都不可靠”。
- Production route: Script V2 strict DSL → `xlbnas@1` exact TTS → Subtitle Timing V2 → `memory-lab-editorial@1` → exact reconciliation → clean master + burned review.
- Success: 来源账本、脚本和素材链可追溯；真实音频决定最终时长；视觉在实际视频中语义对应、状态保持；全片最多两次正式渲染。
- Explicit exclusions: H3、旧 `run-stage`、DeepSeek 阶段执行器、工作流 UI、直接 DB 修补、伪造 succeeded jobs、`latest/current` 推断、依赖升级和架构重写。
