# Extreme Long Video Evidence Ledger

## Project frame

- Working title: 《你记得的，真的发生过吗？——从虚假记忆、目击证词到大脑如何重写过去》
- Core question: 为什么错误记忆仍可能带来强烈确信感；回忆在什么意义上是重建，而不是对过去的逐字读取？
- Audience: 无心理学背景的普通中文观众。
- Claim policy: `SOURCE CLAIM` 只写来源直接支持的结果；`MODERN EVIDENCE` 用后续研究校准；`INTERPRETATION` 明示推论；`LIMITATION` 约束脚本最大措辞。
- Exclusions: 不说“所有记忆都是假的”；不说“每次回忆都会完整改写记忆”；不说“科学家可以随意植入完整人生记忆”；不说“目击证词毫无价值”；不把实验室词表错误等同于复杂创伤记忆。
