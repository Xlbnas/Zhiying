# Extreme Long Video — Argument Tree

## Thesis

记忆不是逐帧回放，而是依据线索、意义、来源判断和后来信息生成当前版本；这种建构通常有用，但在细节、来源、顺序和高风险决策上需要外部校验。

## Main chain

1. 确信感与准确性不是同一指标，但记忆也不是普遍无用。
2. Bartlett 的复述研究提供“重建”历史入口，同时必须交代材料来源、方法差异和复现边界。
3. 误导信息范式说明事后语言可改变后来的报告，但不单独证明原始痕迹被删除。
4. DRM 说明内部语义关系也会生成诱饵词错误；中文词表只作适配演示。
5. 主旨/细节、来源归因、schema、普通干扰和再巩固是候选解释，不是同一条已证实因果链。
6. 自信的诊断价值依赖首次、公平、未污染的程序；反馈会污染后来的元记忆。
7. 闪光灯记忆把“持久确信”和“报告一致性下降”分离出来；一致性不是客观准确率。
8. 司法应用应保护第一次报告、使用双盲/标准指示、即时记录信心并避免反馈。
9. 自传体植入研究证明强提示下可出现错误信念或回忆体验，但比例依赖分类规则，不能外推到具体个案。
10. 结论不是全面怀疑，而是按风险决定何时依赖主旨、何时寻找照片、文字、时间戳和独立证人。

## Strongest objections retained

- 报告改变可能来自反应偏差、干扰或来源判断，不能自动归因于再巩固。
- 高初始自信在严格条件下可能有信息价值，不能概括成“证人越自信越不可靠”。
- 虚假自传体记忆研究的 memory / belief / imagery / compliance 编码仍有方法争议。
- 实验室词表和寻常童年事件不能直接给出现实重大指控的真伪或发生率。
