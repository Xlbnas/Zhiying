## 第二章 弗洛伊德为什么迷人（0:48–1:40）

@delivery slow
弗洛伊德在《日常生活心理病理学》里，把忘记名字、口误、误读误写、忘记办事，还有拿错、弄丢东西，放进了同一个研究计划。<!-- E01 -->

@delivery normal
他的核心想法，不是错误本身会说真话。而是你原本要做、要说的事，可能被另一股没有承认的念头干扰。口误，是两种表达挤到了一起。忘记办事，也可能是心里有一部分根本不想做。<!-- E03 E04 -->

最著名的是西尼奥雷利案例。弗洛伊德忘了那位画家的名字，却不断冒出另外两个相近的名字。他把这些替代词，连回此前关于死亡和痛苦的谈话，认为忘名受到了被避开的联想影响。公平地说，他也承认，并不是所有忘名都来自压抑。<!-- E02 E16 -->

这个解释真正迷人的地方，是它把无意识从梦和诊室，带进了普通人的日常生活。一个小错误，也可能成为观察心理冲突的窗口。<!-- E05 -->

## 第三章 大脑本来就有噪声（1:40–3:05）

但一百多年后的认知心理学，已经有了很多不需要隐藏欲望的解释。

说话不是先在脑子里写好完整句子，再按下播放。词义、词语和语音会一层层激活，多个候选同时竞争。<!-- E06 E07 -->

@delivery normal
大多数时候，监控系统能拦住错误。偶尔错误候选抢先一步，嘴就瓢了。<!-- E06 E07 -->

想不起人名，也不一定神秘。舌尖现象说明，信息可能还在记忆里，只是这一刻取不出来。<!-- E10 -->

忘记买牛奶、回消息或者带钥匙，属于未来意图记忆的问题。一项汇总四十篇研究的系统综述发现，手头的事越费脑，人越容易漏掉稍后要做的任务。<!-- E09 -->

拿错杯子，或者走上每天熟悉、但今天不该走的路，也可以是行动脚本启动得太快。熟练程序先跑了，当前目标没来得及接管。<!-- E08 -->

当然，这不等于动机永远无关。实验确实提示，眼下的语境，可能影响哪一类口误更容易出现。但相关的无意识启动结果，并没有稳定复现。心理状态可能参与竞争，不等于被压抑的欲望已经被抓了现行。<!-- E13 E14 -->

## 第四章 保留问题，放下万能钥匙（3:05–4:10）

弗洛伊德式解释最迷人，也最危险的地方是：错误一发生，我们总能从一个人的经历里，找到一条看起来很吻合的联想链。

可科学解释不能只问，故事讲得通不通。还要问：它能不能提前预测？有没有和词频、语音相似、疲劳、注意下降这些普通原因比较？如果结果正好相反，这套解释会不会也能换一条联想，继续成立？<!-- E12 E15 -->

所以，更稳妥的结论，不是“弗洛伊德全错”，也不是“每次嘴瓢都是真心话”。他的贡献，是逼我们承认：行为并不总对意识完全透明。现代心理学保留了这个问题，却把答案拆成了可以实验的语言、记忆、注意和控制机制。<!-- E05 E06 E08 E11 -->

下一次叫错名字，你当然可以多问一句：我刚才为什么会错？但别急着宣布破案。<!-- E17 -->

@delivery soft
一次失误，可以是线索，也可以只是一个忙碌大脑的噪声。要从错误走到隐藏动机——中间还缺一整条可以检验的证据链。<!-- E17 -->
