## Family and repetition guardrail

- Six rendered families: Archival / Evidence, Editorial Typography, Cognitive Mechanism, Comparison / Debate, Timeline / Evidence Map, Minimal Breath.
- Minimal Breath is limited to S001, S017, and S024; it is no longer the default fallback.
- No family runs for more than two consecutive scenes.
- Existing three archival assets are reused; no asset search is required before the visual grammar itself passes preview.
- Subtitle text remains reading assistance. Main-canvas copy expresses structure, labels, comparison, and evidence level.
